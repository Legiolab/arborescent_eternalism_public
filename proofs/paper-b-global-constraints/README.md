# Online proof repository for Global Constraints Beyond Finite Modal Data

Supports **Global Constraints Beyond Finite Modal Data**, version 1.

[Read the manuscript](../../papers/paper_B/AE_Global_Constraints_V1_Mury.pdf). Cite all versions: https://doi.org/10.5281/zenodo.23256192

The public proof is contained in [prefix_factorisation_theorem.md](prefix_factorisation_theorem.md).

It establishes, under explicit assumptions, a canonical rooted prefix object, a minimal factorisation theorem for prefix-adequate representations and the distinction between an arborescent unfolding and a configuration quotient with diamonds.

The result is conditional representational indispensability. It does not establish the empirical truth of the assumptions, a unique smooth fibre bundle, or superiority over every enriched B-theory.

## Correspondence with the manuscript

The proof file uses a compressed presentation of the manuscript's assumptions and different proposition numbering. The manuscript remains the reference for the full closure criterion.
