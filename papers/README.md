# Public papers

Each public AE paper has its own directory.

A paper directory may contain:
- the public manuscript or preprint;
- a short README identifying its scope and version;
- a `calculations/` directory when reproducible computation is needed to support a published result.

Calculations must be self-contained enough for an independent reader to identify the relevant claim, assumptions, inputs, command or notebook, expected output, interpretation, and limitations.

Internal research material from the private AE repository is not copied here.
