# Paper A — computational checks

These scripts are **reproducibility aids, not proofs**.

Paper A's main results are analytic. The checks here instantiate finite examples used to make the argument inspectable:

1. a rooted prefix structure generated by finite restrictions;
2. a finite approximation to the “phantom ray” example, illustrating that every finite prefix can be locally realised while the corresponding infinite history is excluded by a global admissibility rule;
3. quotienting redundant presentation labels to recover the same prefix invariant;
4. a concurrency diamond in which the serialisations `ab` and `ba` represent the same physical configuration.

Run:

```bash
python src/check_examples.py
```

The script writes `expected_outputs/results.json`. No external Python dependency is required.

The manuscript is intentionally not stored in this public repository while it remains under revision.
